# BlitzFiles Privacy Policy

Last updated: July 23, 2026

BlitzFiles is an open-source file manager. The application does not include analytics or automatic
crash-reporting services and does not intentionally collect or transmit personal information to the
BlitzFiles project.

## Files and device access

BlitzFiles processes file names, paths, metadata, and file contents on the device to perform actions
requested by the user. Root access is requested only when the user enables or invokes functionality
that requires it.

## Remote storage

When the user configures FTP, SFTP, SMB, or WebDAV storage, BlitzFiles communicates directly with
the server selected by the user. File data and the credentials required for that connection are used
only to provide the requested remote-storage functionality. The privacy and security practices of
the selected server are controlled by its operator.

## Diagnostics

Android may record local application logs and crash information. BlitzFiles does not automatically
upload those diagnostics to the BlitzFiles project.

## Third-party links

The application may open links in an external browser, including links to the upstream Material
Files project and open-source license information. External sites have their own privacy policies.

## Security

BlitzFiles uses Android platform security mechanisms, but no method of storage or transmission is
guaranteed to be completely secure. Users should protect device access and use trusted remote
servers and networks.

## Changes

This policy may be updated when BlitzFiles functionality changes. Updates will be published with
the project.

## Contact

Questions about this policy should be submitted through the BlitzFiles project repository.
